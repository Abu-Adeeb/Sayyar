# سيّار | Sayyar

أساس منصة سيّار الرقمية لوساطة تأجير السيارات في المملكة العربية السعودية. يضم واجهة مرجعية للعميل، وبوابة إدارة، وبوابة شريك، ونموذج بيانات تشغيلي قابل لربط مزودي الخدمات لاحقًا.

## الحالة الحالية

- البحث حسب مدينة وطريقة وتاريخ الاستلام ومدة الإيجار.
- عرض فئات تجريبية وأسعار تقديرية واضحة.
- حفظ طلب الحجز في قاعدة D1 وإصدار رقم مرجعي للعميل.
- التحقق من البيانات وحساب السعر في الخادم مع منع تكرار الطلب عند إعادة الإرسال.
- بوابة إدارة عربية/إنجليزية على `/admin` لمتابعة الحجوزات والشركاء وتقييم الفروع والتقارير والصلاحيات والتكاملات.
- بوابة شريك عربية/إنجليزية على `/partners` مع نطاق الفروع والحجوزات والمركبات والتقييمات والتقارير والمستخدمين.
- دورة حجز محكومة تشمل مؤقت حجز مدته 10 دقائق، الدفع، التأكيد، جاهزية المركبة، التنفيذ، الإكمال، الإلغاء والاسترداد.
- صلاحيات تفصل إدارة سيّار عن الشركاء، وتقيّد موظف الشريك بالفروع المصرح بها.
- جداول تشغيلية للشركات والفروع والمركبات والحجوزات والأحداث والتقييمات وطلبات انضمام الشركاء والتكاملات.
- عقود برمجية مستقلة لربط OTP والدفع والمخزون دون تضمين مفاتيح أو مزود وهمي.
- فحوصات آلية للبناء وجودة الكود ومنطق الطلبات.

بيانات البوابتين الحالية مرجعية لتثبيت تجربة الاستخدام والنطاق الوظيفي. لا تصبح بوابات تشغيل فعلية قبل اعتماد نظام الهوية، وربط الاستعلامات بقاعدة الإنتاج، وضبط مزودي OTP والدفع والمخزون.

## القنوات المعتمدة

- تطبيق العميل: قناة البحث والحجز النهائية عند الإطلاق.
- بوابة الشريك: إدارة الحجوزات والمركبات والفروع والتقارير والمستخدمين.
- بوابة الإدارة: إدارة المنصة والشركاء والعمليات والصلاحيات والتكاملات.
- الموقع التجريبي: مرجع للمنتج والتصميم، وليس بديلًا عن تطبيق العميل النهائي.

## التشغيل المحلي

يتطلب Node.js `>=22.13.0` وبيئة Linux.

```bash
npm ci
npm run dev
```

## الفحوصات

```bash
npm run lint
npm test
```

بعد تعديل `db/schema.ts`، أنشئ ترحيلًا جديدًا وراجعه قبل النشر:

```bash
npm run db:generate
```

## التقنية

- React وVinext
- Tailwind CSS ومكونات Shadcn المضمّنة
- Cloudflare Workers وD1
- Drizzle لتوليد ترحيلات قاعدة البيانات

## حدود التكاملات

لا تُحفظ الأسرار في المستودع. يجب على المبرمج تنفيذ Adapter للعقد المناسب في `lib/integrations.ts` ثم حقنه من بيئة الخادم. أي تكامل غير مضبوط يفشل بشكل مغلق بدل تنفيذ عملية وهمية.

راجع [وثيقة الأساس التشغيلي](docs/PLATFORM_FOUNDATION.md) قبل توصيل الهوية أو الدفع أو أنظمة شركات التأجير.
