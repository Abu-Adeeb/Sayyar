# Sayyar | سيّار

واجهة أولية لمنصة **سيّار** لمقارنة وحجز مركبات التأجير من شركات مرخصة في المملكة العربية السعودية. سيّار وسيط تقني؛ عقد التأجير يصدر من شركة التأجير التي يختارها العميل.

## النطاق المنفذ

- واجهة عربية افتراضيًا مع تحويل كامل للواجهة الحالية إلى الإنجليزية.
- ثلاث طرق للاستلام: الاستلام من الفرع، توصيل المركبة، أو طلب تكسي إلى الفرع.
- بحث حسب مدينة وتاريخ ووقت الاستلام وعدد الأيام.
- إعادة المركبة في مدينة مختلفة.
- احتساب تلقائي لتاريخ الإعادة.
- نتائج تجريبية لفئات المركبات مع السعر التقديري.
- تصميم متجاوب للجوال وسطح المكتب.

> البيانات والأسعار الحالية تجريبية لواجهة الـMVP، وليست عروض تأجير فعلية.

## التشغيل المحلي

المتطلبات:

- Node.js `>=22.13.0`
- Linux أو بيئة متوافقة مع `bash` وGNU `timeout`

```bash
npm ci
npm run dev
```

## التحقق

```bash
npm run lint
npm test
```

أمر `npm test` يبني نسخة الإنتاج أولًا، ثم يتحقق من استجابة الصفحة وبياناتها الوصفية ومكونات الواجهة الأساسية.

## التقنية

- React 19 وNext.js 16
- Vinext وVite لاستهداف Cloudflare Workers
- Tailwind CSS 4 ومكونات Shadcn المضمّنة
- TypeScript

## الهيكل الرئيسي

- `app/page.tsx`: الصفحة الرئيسية وتدفق البحث التجريبي.
- `app/layout.tsx`: بيانات الصفحة وإعداد اللغة الافتراضية.
- `app/globals.css`: الهوية البصرية والأنماط العامة.
- `components/ui/`: مكونات الواجهة القابلة لإعادة الاستخدام.
- `tests/`: اختبارات البناء والصفحة والمكونات.
- `.github/workflows/ci.yml`: فحوصات كل Pull Request.

## حالة المشروع

هذه هي مرحلة **أساس محرك البحث والحجز**. تسجيل العملاء، بوابة الشركاء، الدفع، الحجوزات الفعلية، وربط أنظمة شركات التأجير ليست منفذة بعد.
