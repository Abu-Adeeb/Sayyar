# سيّار | Sayyar

واجهة عربية/إنجليزية لمقارنة فئات مركبات التأجير وإرسال طلب حجز مبدئي داخل المملكة العربية السعودية.

## الحالة الحالية

- البحث حسب مدينة وطريقة وتاريخ الاستلام ومدة الإيجار.
- عرض فئات تجريبية وأسعار تقديرية واضحة.
- حفظ طلب الحجز في قاعدة D1 وإصدار رقم مرجعي للعميل.
- التحقق من البيانات وحساب السعر في الخادم مع منع تكرار الطلب عند إعادة الإرسال.
- فحوصات آلية للبناء وجودة الكود ومنطق الطلبات.

طلب الحجز الحالي مبدئي للتحقق من التوفر؛ لا ينشئ عقد إيجار ولا ينفذ دفعة. تسجيل الجوال والتحقق برمز OTP والدفع الإلكتروني وربط مخزون شركات التأجير مراحل لاحقة بعد اختيار مزوديها.

## التشغيل المحلي

يتطلب Node.js `>=22.13.0` وبيئة Linux.

```bash
npm ci
npm run dev
```

## الفحوصات

```bash
npm run lint
npm test
```

بعد تعديل `db/schema.ts`، أنشئ ترحيلًا جديدًا وراجعه قبل النشر:

```bash
npm run db:generate
```
